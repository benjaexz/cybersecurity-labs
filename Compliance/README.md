# Botium Toys — Security Risk Assessment

## Overview

This project presents a security risk assessment and compliance gap analysis based on the fictional organization Botium Toys.

The assessment evaluates existing security controls, identifies vulnerabilities, analyzes potential business impacts, and proposes remediation strategies.

## Objectives

- Assess existing administrative, technical, and physical security controls.
- Identify security gaps and vulnerabilities.
- Evaluate risks associated with sensitive data exposure.
- Analyze selected PCI DSS, GDPR, and SOC-related requirements.
- Develop a prioritized security remediation roadmap.

## Scope

The assessment covers:

- Asset management
- Identity and Access Management (IAM)
- Network security
- Data protection and encryption
- Backup and disaster recovery
- Security monitoring
- Physical security
- Compliance requirements

## Key Findings

1. Excessive access privileges.
2. Unencrypted payment card information.
3. Missing backup and disaster recovery capabilities.
4. Absence of an Intrusion Detection System (IDS).
5. Weak password management and segregation of duties.

## Deliverables

- Security controls assessment
- Compliance gap analysis
- Security findings and risk evaluation
- Remediation recommendations

## Frameworks and Concepts

- NIST Cybersecurity Framework
- PCI DSS
- GDPR
- SOC 1 / SOC 2
- CIA Triad
- Defense in Depth
- Least Privilege

## Disclaimer

This is an educational case study based on a fictional organization and course-provided documentation. It is not an independent security audit, penetration test, or formal compliance assessment.
